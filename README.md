# GChat

GChat is a modern Android messaging application built with Kotlin.

The project is being developed from scratch with a focus on simplicity, privacy, security, and a clean user experience.

## Features

- 💬 One-to-one messaging
- 🔐 End-to-end encryption architecture
- 👤 User profiles
- 🆔 GChat ID
- 📱 QR-based contact sharing
- 📁 File sharing
- 📞 Voice and video calls
- 🌙 Modern dark interface
- 💾 Local message storage

## Technology

- Kotlin
- Android
- Jetpack
- Material Design
- Gradle
- GitHub Actions

## Project Status

🚧 **In active development**

GChat is currently being rebuilt from scratch.

## Build

The project can be built automatically using GitHub Actions.

Successful builds will produce an APK artifact that can be downloaded from the Actions section.
